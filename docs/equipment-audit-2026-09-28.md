檢查目前專案的 165 種裝備、162 筆詳細配裝資料，並對照 2026-09-27 下載的原始試算表快照。快照 SHA-256 與 `drop-data.js` 的來源雜湊一致；套用阿爾納帽人工校正後，重新匯入的道具、魔物、掉落關聯與後期簡表順序均與專案資料一致。

## 同名裝備誤合併

- 六個職業裝備分頁中，唯一重複名稱是「弓箭手」D8、D9 的紅色阿爾納帽。
- D8：7 力、9 敏、113 防，幼龍保護者掉落；保留紅色版本。
- D9：9 力、10 敏、113 防，大爺鬼魂掉落；已依使用者確認改為藍色版本，總和由來源的 16 校正為 19。
- 校正後，同職業、同配裝、同部位的同名裝備沒有相互衝突的詳細資料。不同盜賊配裝分開檢查，避免把正常的力幸／敏幸差異當成誤合併。

藍／綠／紅／黑色艾倫鞋與黑色巴爾鞋的總和包含原表列出的「6 攻」。加上此項後，總和分別為 21、22，沒有發現算術矛盾。這只能確認原表數字相符，不能獨立證明遊戲能力值正確。

## 範圍與重跑方式

本次檢查沒有找到其他與阿爾納帽相同的重複名稱合併問題；並非以遊戲內資料逐件驗證顏色及掉落。若來源僅列一次但名稱本身誤植，且能力值與總和一致，仍可能無法由內部比對識別。本次未重新下載或覆蓋較新的試算表資料。

```powershell
python scripts/audit-chronostory-equipment.py path/to/chronostory-20260927.xlsx
python scripts/test-chronostory-drops.py
```

稽核程式只讀取資料，不修改道具或掉落。省略 XLSX 參數時，只檢查專案快照。防具總和按職業主要能力計算（劍士含命中、法師含原表攻擊力）；武器與無明確總和的資料不進行此項算術檢查。
