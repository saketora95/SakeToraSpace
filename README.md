# SakeTora Space

遊戲與生活的小工具集合。繁體中文、響應式黑色與深紅色介面，使用原生 HTML / CSS / JavaScript，無套件依賴與建置步驟。

首頁直接呈現工具清單、搜尋與分類；網站介面不放置通往 GitHub 的連結。

## 已有功能

- 工具搜尋、仙境傳說 / FFXIV / ChronoStory 分類及收藏。
- 「工具」與「連結」核選方塊可篩選顯示類型，預設皆勾選；同時套用至卡片及側邊子選單，可搭配搜尋、分類與收藏使用。皆不勾選時會顯示提示，「顯示所有工具」可重設全部篩選。
- 有有效收藏時，首頁優先顯示「我的收藏」，否則顯示「所有工具」。已移除工具的收藏不會顯示。
- 「所有工具」不展開子選單；其餘分類可展開，切換分類時原選單自動收合。空分類顯示「該分類下沒有工具」。
- 手機可使用「工具選單」按鈕開啟導覽。
- 「仙境傳說」提供「倒數計時」，預設 55 秒。有效秒數範圍為 1–86400 的整數，修改後自動保存至目前瀏覽器。

- 點擊整張卡片即可開啟工具；收藏星號獨立操作，不會開啟工具。
- 「仙境傳說官方網站」提供 https://ro.gnjoy.com/ 外部連結，卡片與側邊選單都會另開分頁，也可加入收藏。
- 另收錄台灣（https://ro.gnjoy.com.tw/）、日本（https://ragnarokonline.gungho.jp/）、iRO（https://renewal.playragnarok.com/）與泰國（https://ro.gnjoy.in.th/home/）網站。
- 卡片採緊湊排版，縮小高度、內距、圖示與卡片間距。
- 卡片依分類呈現可收合區塊，預設展開；「所有工具」及收藏也保留分類分組。各分類先列工具、再列連結，兩者使用獨立網格，工具未滿一列時連結仍從新列開始。篩選後沒有項目的分類不顯示。
- 仙境傳說另收錄 Divine Pride、Landgris ROCalculator 及 rd.fharr.com 連結。
- FFXIV 分類收錄 FF14 灰機 Wiki、Eorzea Collection 裝備套裝、Lodestone 伺服器狀態及 Paissa 連結；Paissa 保留 `world=50&sort=size:2` 查詢參數。

## 冰晶武器價格

提供「冰晶武器價格」（`glacier-weapon`），各素材單價獨立輸入，修改時立即更新取得方式與價格表格，不會改寫其他欄位。有效輸入自動保存至 localStorage，下次瀏覽時載入；無效輸入不覆蓋已保存的價格。

- 基礎費用為「雪花的花葉單價 × 500 ＋ 150,000 × 0.76」。
- 輸入順序為花葉、原石、兌換證、雪花魔石、閃耀雪花魔石、耀眼雪花魔石；既有保存價格仍對應原素材。表格的基礎費用位於雪花魔石之前，使用一般素材數值樣式。
- 雪花魔石比較直接購買、5 個雪花魔力原石，以及「兌換證單價 ＋ 7,500」。後續兩級使用下級魔石最低成本 × 5，包含先用原石或兌換證取得下級魔石的方案。
- 閃耀雪花魔石比較直接購買、5 顆雪花魔石的最低取得成本，以及「兌換證單價 × 2 ＋ 25,000」。
- 耀眼雪花魔石比較直接購買、5 顆閃耀雪花魔石的最低取得成本，以及「兌換證單價 × 3 ＋ 100,000」。
- 每種魔石顯示最低單價及取得方式，同價時並列。升級可使用較低階魔石的購買或兌換方案。
- 三種組合用量為 50/60/30、75/65/45、75/75/70，總價採各魔石最低成本，再加基礎費用。

預設單價依序為：雪花魔力原石 3,500、雪花魔石 10,000、閃耀雪花魔石 40,000、耀眼雪花魔石 100,000、雪花的花葉 15,000、魏格納商隊兌換證 4,000。預設基礎費用為 7,614,000，三種組合總價依序為 13,094,000、15,009,000、17,839,000 Zeny。基礎費用顯示於價格表格中，表格上方僅保留公式。

兌換證未填時排除兌換方案，填 0 代表免費取得兌換證但仍需支付兌換費。價格不代表即時市價；儲存資料損毀時，受影響欄位回復預設。

## 改造素材價格

依 `reformMaterialCalc.html` 與其計算腳本移植，輸入影子神秘金屬單價與四級強化石數量，即時計算總價及所需金屬數量，並列出原石與強化石換算單價。有效輸入自動保存，可重設為預設值；無效欄位保留並顯示無法計算，不影響其他可計算的結果。

- 預設金屬單價 50,000 Zeny、影子神秘原石單價 10,000 Zeny，各級數量 100；原石輸入框排列在金屬之前。輸入框下顯示交易辨識提醒，並以 20 個原石合成 1 個金屬、不計額外費用比較購買成本。原石單價不納入快速試算，既有保存值會保留，按重設即可套用新預設值。
- 下級成本為金屬單價加 20,000；中、高、頂級依序為前一級成本乘 3，再加 10,000、20,000、50,000。
- 每顆強化石需要的金屬數量依序為 1、3、9、27。
- 影子神秘原石單價為金屬單價除以 20；各級強化原石單價為強化石成本扣除 10,000、20,000、50,000、100,000 後除以 5。
- 素材表格列出的推薦上限價格以直接購買影子神秘金屬再兌換的成本為基準，收購價低於上限才更划算，等於上限為同價。
- 試算與購入上限整合於同一張表格：各級強化石名稱下顯示兌換公式，每列列出數量、合計成本、金屬需求量及強化石／強化原石的每個購入上限。數量使用一般文字輸入框，僅接受範圍內的非負整數。
- 預設四級總價為 7,000,000、22,000,000、68,000,000、209,000,000 Zeny。
- 單價接受 0 至 1,000,000,000 的整數，數量接受 0 至 100,000 的整數，以保持總價在安全整數範圍內。

## 倒數計時操作

- 時間與操作按鈕之間固定顯示狀態：準備就緒、計時中、已暫停、時間到。
- 開始：開始倒數，暫停後按開始可繼續。
- 暫停：保留剩餘時間。
- 停止：停止倒數與音效，回到使用者設定的秒數。
- 計時中只能暫停或停止；到時後只能停止。開始後到停止前不能修改秒數。
- 到時重複播放雙嗶音效，直到按停止、用 X 關閉工具或離開網頁。
- 按 Escape 或 X 關閉工具，同時停止計時與音效；點擊外圍不會關閉工具。

收藏及秒數使用 localStorage 保存，不跨裝置同步；清除網站資料會移除設定。重新整理只還原設定秒數，不繼續前次倒數。音效由瀏覽器 Web Audio 產生，不需下載音效檔。裝置靜音、瀏覽器音訊限制或背景分頁暫停可能影響提醒。

## 本機預覽

直接開啟 `index.html`，或在專案根目錄執行：

```sh
python -m http.server 8000
```

瀏覽 http://localhost:8000 。建議透過 HTTP 預覽，以取得一致的本機儲存行為。

## 發佈到 GitHub Pages

1. 將這些檔案 commit 並 push 到 GitHub 儲存庫的 `main` 分支。
2. 開啟儲存庫 **Settings → Pages**。
3. **Build and deployment → Source** 選擇 **Deploy from a branch**。
4. 選擇 `main`、`/ (root)`，按下 **Save**。
5. 等待 Pages 部署完成，網站預期位址為：
   https://saketora95.github.io/SakeToraSpace/

此專案包含 `.nojekyll`，適合直接發佈靜態檔案。所有站內資源使用相對路徑，可部署於 GitHub Pages 的儲存庫子路徑。若儲存庫為私人，請確認 GitHub 方案支援 Pages。

## 新增工具

1. 在 `assets/js/app.js` 的 `tools` 陣列加入唯一 `id`、名稱、分類、圖示、配色、介紹及搜尋關鍵字。
   分類 `category` 使用 `ragnarok`（仙境傳說）、`ffxiv`（FFXIV）、`chronostory`（ChronoStory）；通用工具使用 `null`。
2. 站內工具程式放入 `assets/js/tools/<分類>/`，在 `index.html` 中以 `defer` 載入，排列於 `assets/js/app.js` 之前；接著在主程式的 `renderers` 物件登記工具 ID 與繪製函式，將畫面放進 `#tool-content` 並綁定事件。外部連結改為設定 `url`，不需要 renderer。
3. 若新增計時器或音效等資源，請同步處理關閉工具及離開頁面時的清理。
4. 更新 README 功能清單；側邊工具選單與總數會依工具目錄自動產生。

`tools` 目錄視為可信任的開發者內容；使用者輸入請透過 `textContent` 或 `value` 顯示，避免注入 HTML。

## 建議驗收

- 所有工具顯示倒數計時與官網連結；卡片任意位置可開啟，收藏星號不觸發開啟，官網連結另開分頁。
- 所有工具沒有展開按鈕，其餘分類展開、收合與空分類提示正常；切換分類最多保留一個展開選單。
- 初次使用顯示 00:55，修改秒數並重新整理後仍保留設定；無效儲存值退回 55 秒。
- 開始、暫停、繼續、停止及時間到達後的按鈕狀態正確。
- 時間到達後音效反覆播放；停止、X 關閉或離開頁面後音效立即停止。
- 點擊工具外圍不會關閉工具；Escape 或 X 關閉後焦點回到原按鈕。
- 手機版三個操作按鈕等寬填滿一列，沒有水平溢出。
