此專案主要由 AI 生成與建置，收集遊戲與日常使用的小工具及參考連結。

## v0.07（2026-10-02）

- **轉職資訊**：提供一至四轉等級與流程、可展開的各職業地點、三轉考試題庫，以及四轉正攻法與秘咒法說明；四個項目均預設收合。

### 掉落資料與更新

資料來自[原始 Google 試算表](https://docs.google.com/spreadsheets/d/1Wj4P9_RNcUoW8xgC0yZy5WGqFDurZLZjNzknTdODA1U/edit)，於 2026-09-27 匯入後期簡表、六個職業裝備分頁、武器卷軸與防具卷軸；排除「注意事項」與「四轉流程」，並沿用既有停用裝備排除規則。目前有 379 種道具、202 種魔物及 765 筆掉落關聯，包含新增的童話村資料，查詢使用本地快照，不需連線至 Google。

職業查詢預設顯示所有職業，可複選職業與部位；盜賊分為力量／幸運、敏捷／幸運兩種配裝。結果清單顯示最高能力值總和，並以完整資料中同職業、同部位的最高值標示裝備（包含並列），道具明細亦會標註。盜賊配裝分別比較，劍士另比較表中命中換算後的總和；未知數值不參與比較。

人工校正：大爺鬼魂掉落「藍色阿爾納帽」，能力值為力量 + 9、敏捷 + 10、物理防禦 + 113，最高能力值總和為 19；幼龍保護者仍掉落「紅色阿爾納帽」。匯入器會套用此校正，避免重新匯入時覆蓋。

- `assets/js/tools/chronostory/drop-data.js`：可直接載入的資料，包含 `items`、`monsters`、`drops` 與來源資訊；道具及魔物以名稱產生穩定 ID，掉落關聯使用 `itemId` / `monsterId`。
- 掉落率使用百分比數值，例如 `0.24` 代表 `0.24%`；未記載的機率顯示「未記載」，異常或不一致的機率標示「待確認」。
- 卷軸成功率與掉落率分開顯示；裝備提供等級／幸運需求、最高屬性與最高屬性總和。效果統一使用完整能力名稱與「能力值 + 數值」，例如「力量 + 2」；「71+100 防」拆成「物理防禦 + 71、魔法防禦 + 100」。
- `stats`、配裝名稱與屬性總和的文字在匯入時完成格式轉換，直接寫入 `drop-data.js`，客戶端僅顯示資料。資料格式版本為 3，另以 `summary` 保留後期簡表的地區與魔物順序，不包含逐筆分頁、儲存格位置及原始儲存格文字。
- 查詢頁提供遊戲資料與簡要的來源連結、更新日期，省略試算表欄位對照及逐筆紀錄。

更新時將試算表下載為 `.xlsx`，執行以下指令（Python 3.10 以上，僅用標準函式庫）：

```powershell
python scripts/import-chronostory-drops.py path/to/source.xlsx --date YYYY-MM-DD
python scripts/test-chronostory-drops.py
node scripts/test-chronostory-drop-search.cjs
```

匯入器會跳過排除的分頁、處理合併儲存格、統一卷軸簡稱並合併重複關聯；地區依欄位標題讀取，可支援新增及重新排序的地區。法師分頁支援目前的「法師」及舊版「法師 (五速)」名稱；舊版「法師 (四速)」僅供類型參考，不匯入其屬性與掉落。遇到未知分頁或無法解析的掉落資料會停止，避免靜默漏資料。更新後請同步修改上述匯入日期與筆數。JavaScript 查詢測試需安裝 Node.js。取代器文字框高度同步可執行 `node scripts/test-replacer-resize.cjs` 驗證。

## 工具書籤

在首頁開啟工具時，網址會自動加上 `#tool=工具ID`，可直接複製網址分享或加入瀏覽器書籤。使用者開啟該網址或重新整理時，會直接開啟指定工具；上一頁／下一頁也會同步切換工具。

例如：`index.html#tool=chronostory-support-info`（共享輔助狀態資訊）、`index.html#tool=chronostory-job-info`（轉職資訊）、`index.html#tool=ragnarok-timer`（倒數計時）。獨立頁面工具可直接分享該頁面的網址。
